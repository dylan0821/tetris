# 俄罗斯方块

双击 `俄罗斯方块.html`，用浏览器打开即可。全部样式和逻辑都在这个文件里，无需安装、联网或启动服务器。

## 操作

| 按键 | 功能 |
| --- | --- |
| 左右方向键 | 左右移动 |
| 上方向键 / X | 顺时针旋转 |
| Z | 逆时针旋转 |
| 下方向键 | 加速下落 |
| 空格 | 直接落下 |
| C | 暂存或交换方块，每次落定前限一次 |
| P / Esc | 暂停或继续 |
| Enter | 开始游戏，或从暂停中继续 |

窄屏及触屏设备显示操作按钮，左右移动和加速下落支持长按。切换窗口或隐藏页面时自动暂停。

## 规则

- 七种方块采用七袋随机，每袋各出现一次。
- 提供落点预览、三个后续方块预览和一个暂存位置。
- 一次消除一至四行分别获得 100、300、500、800 基础分，再乘以当前等级。
- 每消除十行提升一级，下落速度逐步增加。
- 加速下落每格一分，直接落下每格两分。
- 最高分保存在当前浏览器本地；若浏览器禁止存储，游戏仍可正常运行。
- 支持旋转时的边缘位置调整及短暂落地延迟；并非竞技版官方旋转规则的完整复刻。

## 音效与动画

- 开始、旋转、暂存、落地、消行和结束时播放轻量合成音效，无需额外音频文件或联网。
- 点击“音效：开 / 关”可切换静音，设置保存在当前浏览器。音频在首次键盘或触摸操作后启用；不支持音频时仍可正常游戏。
- 消行时播放约 0.36 秒的亮光与碎片动画，完成后移除满行并生成下一块；动画期间暂停方块操作。
- 暂停会冻结动画，重开会清空动画。系统启用“减少动态效果”时使用短暂淡出，不显示碎片。

## 验证

已使用 Node 执行脚本语法和核心逻辑检查，覆盖七袋随机、消行、计分、升级、暂存限制、边界碰撞、旋转、暂停、结束、重开及 1,000 次随机操作。尚未进行真实浏览器画面与触屏实测。

新增音效与动画逻辑检查已通过：音效调用与静音、一至四行消除、动画期间操作锁定、暂停恢复、重开清理、减少动态效果及 1,000 次随机操作。实际音色与浏览器动画效果尚未实测。
